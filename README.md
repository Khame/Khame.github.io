# Khame.github.io

Strona: <https://khame.github.io/> — pakiety i programy dla Void Linuxa, po polsku i po angielsku.

Dwa pliki HTML i katalog z obrazkami. Bez builda, bez zależności. GitHub Pages serwuje katalog główny gałęzi `main`, więc push publikuje stronę.

| Plik | Co to |
| --- | --- |
| `index.html` | wersja polska, `/` |
| `en/index.html` | wersja angielska, `/en/` |
| `assets/` | zrzut menu sensei310-tray i podgląd do social mediów |

Podgląd lokalny:

```sh
python3 -m http.server 8000
```

Treść siedzi w obu plikach osobno, razem z CSS i JavaScriptem, więc każdą zmianę robi się dwa razy.

Kod i treści są moje. Jeśli chcesz czegoś użyć, napisz.
