Instalacja

Dodaj repozytorium i zsynchronizuj indeks:

Repozytorium
sudo sh -c 'echo "repository=https://khame.github.io/void-packages/" > /etc/xbps.d/10-khame.conf'
sudo xbps-install -S

XBPS zapyta o import klucza. Sprawdź go i potwierdź import.

Następnie zainstaluj wybrany pakiet:

asusctl
sudo xbps-install asusctl
Double Commander
sudo xbps-install doublecmd
rivalcfg
sudo xbps-install rivalcfg
sensei310-tray
sudo xbps-install sensei310-tray

Pakiet sensei310-tray instaluje rivalcfg jako zależność. Wymaga KDE Plasma i kdialog. Po instalacji skonfiguruj dostęp do myszy według README rivalcfg (reguły udev i grupa plugdev).

Uruchomienie usługi asusd i instalację widgetu Plasma opisuję w README asusctl.

Aktualizacje: sudo xbps-install -Su
